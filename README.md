## 🐛 Melaporkan Bug

Jika Anda menemukan bug di aplikasi ini, silakan **[buat issue baru](https://github.com/Fedha99/ITHelperapp/issues/new?template=bug_report.md)** dan isi template yang disediakan.

### Panduan Pelaporan Bug:
- Berikan deskripsi yang jelas
- Sertakan langkah-langkah untuk mereproduksi
- Lampirkan screenshot atau video jika perlu
- Sebutkan OS dan browser yang Anda gunakan
